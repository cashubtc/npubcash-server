# npub.cash frontend

The public npub.cash homepage, built with React, TypeScript, Vite, Tailwind CSS,
and shadcn/ui. The server and production container serve the compiled files from
`packages/frontend/dist`.

## Development

Run commands from this directory:

```bash
bun run dev
bun run lint
bun run build
```

## Adding shadcn components

```bash
bunx --bun shadcn@latest add button
```
